# GW2 Black Lion Market Tool

A Python-based tool to track supply and demand on the Guild Wars 2 Black Lion Market.

## Setup
1. Install requirements: `pip install -r requirements.txt`
2. Add your API key to `main.py` (or configure a `.env` file).

## Usage
- **Sync Items**: `python main.py --sync`
- **Start Tracker**: `python main.py --track`
